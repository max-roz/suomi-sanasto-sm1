# <img src="https://flagcdn.com/w40/fi.png" width="28" alt="FI"> Suomen sanasto A1 — Тренажер финской лексики

Бесплатный интерактивный веб-тренажер для изучения базового словарного запаса финского языка (уровень A1). Приложение не требует регистрации, работает прямо в браузере и адаптировано как для компьютеров, так и для смартфонов. Поддерживает озвучивание финских слов и фраз (только для Android).

👉 **[Открыть тренажер онлайн](https://max-roz.github.io/suomi-sanasto-A1/SuomenSanastoA1.html)**

---

## ✨ Возможности тренажера

* **9 тематических разделов (соответствуют 9 урокам учебника SM1):** изучение лексики по темам (знакомство, погода, семья и одежда, распорядок дня, дом, город и путешествия, еда, работа). Можно тренировать как одну тему, так и несколько сразу.
* **Три режима работы:**
  * **Карточки:** знакомство с новыми словами и их переводом.
  * **Тест:** выбор правильного перевода из 4 вариантов с умным подбором похожих слов.
  * **Ввод:** тренировка правописания с клавиатуры (есть встроенная панель с финскими буквами `ä`, `ö`, `å` и кнопка подсказки).
* **Озвучка произношения:** автоматическое и ручное озвучивание финских слов и фраз (только для Android).
* **Гибкие настройки:** переключение направления перевода (`Fi → Ru` и `Ru → Fi`), выбор длины раунда (10, 20 или все слова), а также светлая и тёмная темы оформления.
* **Сохранение прогресса:** выученные с первой попытки слова запоминаются в браузере и больше не попадаются в тестах, пока вы сами не сбросите прогресс. В конце раунда доступна работа над ошибками.

## 💻 Как запустить локально (без интернета)

Весь тренажер собран в один автономный HTML-файл, поэтому его можно сохранить на устройство и заниматься офлайн:

1.Скачайте [ZIP-архив репозитория](https://github.com/max-roz/suomi-treeni/archive/refs/heads/main.zip) и распакуйте его.
2. Откройте скачанный файл двойным кликом — он запустится в вашем браузере.



## 🛠 Технологии

Проект написан на чистом **HTML5**, **CSS3** и **Vanilla JavaScript** без использования сторонних фреймворков и серверной части. Для озвучивания текста используется Web Speech API и Google TTS.
